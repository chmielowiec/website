# chmielowiec.net

A minimal personal website for myself. A light, typography-led design with an animated
network of connections, email contact and links to GitHub and LinkedIn. Follows the
system light/dark colour scheme.

Hosted on Apache (OVH): `.htaccess` forces `https://chmielowiec.net` (no `www`) and sets
security and cache headers. `og-image.png` is the social preview card.
